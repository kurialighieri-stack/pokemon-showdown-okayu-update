# Okayu Update alpha.4 — Linux y Windows x64

Esta alfa añade el gestor para Windows x64 sobre el ZIP oficial de Pokémon Showdown Pro 1.2.0 y conserva la versión Linux con Glass experimental.

- **Linux:** extrae el ZIP Linux, instala Python 3.10 o posterior y Zenity, cierra Pro y ejecuta `sh Okayu-Update.sh`. Admite el AppImage original o una distribución extraída compatible de Pro 1.2.0.
- **Windows:** extrae el ZIP Windows en una ruta corta, instala Python 3.10 o posterior con el lanzador `py`, cierra Pro y abre `Okayu-Update.cmd`. El lanzador solicita permisos de administrador mediante UAC. Selecciona el ZIP oficial de Pro 1.2.0 Windows x64 o una carpeta que coincida con las huellas admitidas.
- **Showdown+:** el gestor importa el XPI oficial 1.4, incluido el detectado en Firefox. **Este proceso requiere Python**, porque Okayu Update es un gestor Python. La extensión de Firefox por sí sola no requiere Python. Los paquetes no incluyen Python ni el XPI.
- Windows incorpora rendimiento/cine/streamer, avisos Unown, tema Okayu e icono propio, Showdown+ con Solrock/Lunatone e idiomas de Calcdex. Glass se excluye de Windows.
- Bloqueo de operaciones, comprobación de procesos Windows, preparación del ZIP original y acceso propio de Inicio. Respaldos externos y reversión exacta.
- Huellas Windows verificadas contra el ZIP oficial; compilación de Calcdex con el Node incluido en Pro y adaptación de las rutas de pnpm para Windows.

Python para Windows: https://www.python.org/downloads/windows/

Consulta las instrucciones completas de ambos sistemas en el README y los resultados y límites en `docs/VALIDATION.md`. No se midieron FPS ni consumo GPU en Windows; la revisión visual manual completa de los diálogos Windows sigue pendiente. Sigue siendo una versión alfa para Pro 1.2.0, sin compatibilidad automática con versiones futuras.

Descarga el ZIP de tu sistema y verifica su suma en `Pokemon-Showdown-Okayu-Update-v0.1.0-alpha.4.sha256`. Los archivos «Source code» generados por GitHub no son los paquetes preparados de cada sistema.
